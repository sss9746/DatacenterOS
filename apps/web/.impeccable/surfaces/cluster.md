# Cluster operations
Mode: Operate. Route: /. Source: src/app/App.tsx.
The team's P4 plan supplies the surface, stack, task and visual direction. This work follows that brief directly, code-first.

## Direction contract
THESIS: Put GPU placement and durable training work in one glance, with recovery evidence directly beside them. The topology is the primary view, not a row of oversized metrics.

OWN-WORLD: Ink-blue shell, slate panels, measured off-white typography. Mint marks agent activity, amber marks thermal concern, red marks failure. System sans for controls and tabular monospace only for identifiers and measurements. Thin separators, consistent controls, no glows.

STORY: Locate a hot rack, inspect its GPU and affected job, then follow incident evidence and action status. Read policy comparisons only when real evaluation rows arrive.

FIRST VIEWPORT: A compact masthead and section navigation; run controls below the title. The eight-by-eight matrix leads the left column and job recovery leads the right. A cooling-domain bracket groups r2–r4: selecting a GPU exposes its ID and job without hiding the cluster. Smaller screens stack these regions while keeping all eight GPU columns accessible.

FORM: Team-pinned operator dashboard, no concept roll. Night-shift use and the explicit dark-console brief determine the dark surface. Responsive web controls and real semantic tables.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
