# @dcos/physics fixtures (P1)

All generated, never hand-edited (tests fail on drift). Contract: CONTRACTS v1.1.1. The `gpu_demo_8` run clock starts at
`sim_time_ms = 600000` (§0.12 #2).

- `gpu/`: ObservedSnapshot, tick result and XID-79 signal for preset `gpu_demo_8` (P1-1), generated from the real
  model by `scripts/make-gpu-fixtures.ts`. P2's mock client and P3/P4 build against these. See `gpu/README.md`,
  including what changed in v1.1.1.
- `scenarios/`: the 20 seeded evaluation scenarios (P1-9). Fault `start_sim_time_ms` is absolute (≥ 600 000);
  `horizon_s` is relative to the run start. `scripts/make-scenarios.ts` bundles them into `src/gpu/scenarios.data.ts`.
- `evaluation/`: `runScenario` results for `reactive`, `threshold` and the do-nothing reference over all 20 scenarios
  (P1-9b, for P4's scoreboard), generated by `scripts/make-baseline-results.ts`. See `evaluation/README.md`.

Every fixture passes `validatePayload` from `@dcos/contracts` (the do-nothing rows only with a contract policy label).
